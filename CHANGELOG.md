## [v0.22.0] - 2026-09-20

### Highlights

- SLA exception notification letters: JSON IR, Pandoc Markdown, JSON Schema, and the govex slaletter CLI
- Vulnerability-intelligence packages: NVD CVE-history client, CVE-ID parser, security exception-request model, and package-info supply-chain reference data

### Added

- `slaexception`: new package generating SLA exception notification letters via an `Exception{}` JSON IR (schema 1.0), Pandoc Markdown from `Markdown()`/`WriteMarkdownFile()`, and JSON Schema for agent integration ([`ff82a81`](https://github.com/grokify/govex/commit/ff82a81))
- `govex slaletter` CLI with `generate`, `schema`, and `example` subcommands ([`fec9e56`](https://github.com/grokify/govex/commit/fec9e56))
- `nvd`: NVD CVE History API client with `Client.GetCVEHitory()` returning `CVEHistoryResponse`, millisecond ISO-8601 timestamp handling, and the `getcvehist` CLI ([`96c7e06`](https://github.com/grokify/govex/commit/96c7e06))
- `cve`: `ParseCVEIDs()` extracting CVE IDs from arbitrary text, with a `parse` CLI ([`184493e`](https://github.com/grokify/govex/commit/184493e))
- `exceptionrequest`: `Request{}`/`Requests` and `RequestSet.Status()` modeling vulnerability risk-exception requests through an approval workflow with table rendering ([`089d4bc`](https://github.com/grokify/govex/commit/089d4bc))
- `govex`: `Policy{}` capturing an SLA policy at a point in time ([`8939788`](https://github.com/grokify/govex/commit/8939788))
- `severity`: `Mitigation{}` linking a vulnerability to its mitigation reason and residual risk ([`8939788`](https://github.com/grokify/govex/commit/8939788))
- `pkginfo`: `PkgInfo{}`/`PkgInfos` with reference lists of publicly-disclosed compromised npm packages and the `qixevent` CLI ([`5cc774f`](https://github.com/grokify/govex/commit/5cc774f))
- `fileroutes`: JSON-serializable `FileRouteMap{}` mapping URL paths to source files and HTTP methods/handlers ([`33b8159`](https://github.com/grokify/govex/commit/33b8159))
- `analyzers/semgrep`, `analyzers/spotbugs`: `parse` CLIs for analyzer output ([`150a587`](https://github.com/grokify/govex/commit/150a587))
- `cmd/dedupe`, `cmd/siteindex`: standalone utility CLIs ([`dc5b5e8`](https://github.com/grokify/govex/commit/dc5b5e8))

### Fixed

- `severity`: corrected inverted SLA status logic in the dormant sla.go helper ([`691b032`](https://github.com/grokify/govex/commit/691b032))

### Documentation

- Package guides for slaexception, nvd, cve, exceptionrequest, pkginfo, and fileroutes; govex slaletter, dedupe, and siteindex CLI references; semgrep/spotbugs parse CLI notes; v0.22.0 release notes ([`cfd5e79`](https://github.com/grokify/govex/commit/cfd5e79))

## [v0.21.0] - 2026-08-22

### Highlights

- Residual risk model: compensating controls, inherent vs. residual severity and risk, and exception-driven SLA switching
- Titled vulnerability reports in Markdown, HTML, and PDF via the new vulnreport package and govex report subcommand

### Added

- `govex`: `CompensatingControl{}` linking controls to reduced risk dimensions and the CVSS environmental metrics they justify ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `govex`: `ExceptionStatus{}` for risk exception approval state with expiry via `IsApprovedAt()` ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `govex`: `Vulnerability{}` residual fields: `SeverityResidual`, `SeverityResidualVector`, `RiskInherent`, `RiskResidual`, `Controls`, `Exception` ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `govex`: `EffectiveSeverity()` SLA policy: inherent severity until exception approval, then residual severity while approval is in effect ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `govex`: `ValidateResidualSeverity()` restricting residual severity to Critical-Low and at most the inherent severity ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `govex`: report fields for residual severity, effective severity, inherent/residual risk, controls, and exception status ([`a593dbd`](https://github.com/grokify/govex/commit/a593dbd))
- `risk`: new package with likelihood x impact `Rating{}` and explicit `Matrix{}` policy objects referenced by ID ([`f73c6b9`](https://github.com/grokify/govex/commit/f73c6b9))
- `risk`: NIST SP 800-30 Rev. 1 levels with published semi-quantitative values and canonical-scale translators including `TranslateRatingToNIST80030()` ([`f73c6b9`](https://github.com/grokify/govex/commit/f73c6b9))
- `cvss`: version-specific qualitative severity rating scales aligned with NVD for CVSS v2.0, v3.x, and v4.0 via `SeveritySetForVersion()` ([`1f1dc0e`](https://github.com/grokify/govex/commit/1f1dc0e))
- `reports/vulnreport`: new package rendering a `VulnerabilitiesSet{}` as titled Markdown, HTML, and PDF reports with per-finding detail sections ([`1f2db6d`](https://github.com/grokify/govex/commit/1f2db6d))
- `reports/vulnreport`: default and residual-aware findings column sets ([`1f2db6d`](https://github.com/grokify/govex/commit/1f2db6d))
- `govex report` CLI subcommand generating reports from VulnerabilitiesSet or Report JSON with format inferred from output extension ([`658ed03`](https://github.com/grokify/govex/commit/658ed03))

### Fixed

- `severity`: `SLAStatusTimesString()` returned "Within SLA" for overdue items and "Out of SLA" for compliant ones ([`73efbba`](https://github.com/grokify/govex/commit/73efbba))
- `severity`: severity-to-score markdown table showed Low as 1.0-3.9 instead of 0.1-3.9 ([`1f1dc0e`](https://github.com/grokify/govex/commit/1f1dc0e))

### Dependencies

- _2 dependency updates_

### Documentation

- Compensating Controls & Residual Risk reference; risk and vulnreport package guides; `govex report` CLI reference; SLA reference rewritten around the actual API ([`1ac690e`](https://github.com/grokify/govex/commit/1ac690e))
- Roadmap with Phase 1 residual risk and reporting RMIs ([`f32eac8`](https://github.com/grokify/govex/commit/f32eac8))
- README: update shields ([`b4b48a9`](https://github.com/grokify/govex/commit/b4b48a9))
