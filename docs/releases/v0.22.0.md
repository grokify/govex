# v0.22.0 Release Notes

**Release Date:** September 21, 2026

## Highlights

This release adds **SLA exception notification letters** — a JSON IR, Pandoc Markdown output, JSON Schema, and the new `govex slaletter` CLI — alongside a set of **vulnerability-intelligence packages**: an NVD CVE-history client, a CVE-ID parser, a security exception-request model, and package-info supply-chain reference data.

## New Features

### SLA Exception Letters

The new `slaexception` package generates SLA exception notification letters from a versioned JSON IR (`schema_version` 1.0):

- **`Exception`** - The document model, with `Sender`, `Finding`, `CVSS`, `SLA`, `Milestone`, and `Approver` sub-types and snake_case JSON tags
- **`Markdown()` / `WriteMarkdownFile()`** - Pandoc-style Markdown output for conversion to DOCX/PDF
- **JSON Schema** - Emitted for AI-agent integration
- **`govex slaletter`** - CLI with `generate`, `schema`, and `example` subcommands

```go
e := slaexception.Exception{
    Subject:      "SLA Exception – Low – Missing rate limiting",
    Sender:       slaexception.Sender{Name: "Jane Smith", Title: "Security Engineer", Company: "Acme Corp", Email: "security@acme.com"},
    CustomerName: "Widget Inc",
    Application:  "Payments API",
    Finding:      slaexception.Finding{Title: "Missing rate limiting", Severity: "Low", Identifier: "APPSEC-1234", DetectedOn: "2026-04-01"},
    SLA:          slaexception.SLA{TargetDays: 90, OriginalDueDate: "2026-06-30", NewDueDate: "2026-07-31"},
    Mitigations:  []string{"WAF rate limiting rules in place"},
}
md := e.Markdown()
```

```bash
govex slaletter example                                   # print an example JSON IR
govex slaletter schema                                    # print the JSON Schema
govex slaletter generate --input finding.json --output-md letter.md
```

See the [SLA Exception package](../packages/slaexception.md) and [govex slaletter](../cli/slaletter.md) references.

### NVD CVE History Client

The new `nvd` package wraps the NIST NVD CVE History API:

- **`Client.GetCVEHitory(ctx, cveID)`** - Returns a `CVEHistoryResponse` of `CVEChange` events, with custom unmarshaling for NVD's millisecond ISO-8601 timestamps
- **`getcvehist`** - CLI for fetching a CVE's change history

See the [NVD package](../packages/nvd.md) reference.

### CVE-ID Parsing

The new `cve` package extracts CVE identifiers from arbitrary text:

- **`ParseCVEIDs(s)`** - Case-insensitive extraction of `CVE-YYYY-NNNN` IDs
- **`parse`** - CLI wrapping the parser

See the [CVE package](../packages/cve.md) reference.

### Security Exception Requests

The new `exceptionrequest` package models vulnerability risk-exception requests through an approval workflow:

- **`Request` / `Requests`** - Exception requests with requestor, department, exposure flags (PII, tenant compromise, lateral movement), compensating controls, CVSS, and closure state, plus `Table()` rendering
- **`RequestSet.Status()`** - Categorizes requests into approved, in-progress, and closed via `StatusStats`

See the [Exception Request package](../packages/exceptionrequest.md) reference.

### Supporting Packages and Tools

- **`govex` `Policy`** - Captures an SLA policy at a point in time (`SLA severity.SLAMap`, `SLAAtTime`)
- **`severity` `Mitigation`** - Links a vulnerability to its mitigation reason and residual risk
- **`pkginfo`** - `PkgInfo` / `PkgInfos` with reference lists of publicly-disclosed compromised npm packages (Qix / Shai-Hulud incidents) and the `qixevent` CLI
- **`fileroutes`** - JSON-serializable `FileRouteMap` mapping URL paths to source files and HTTP methods/handlers
- **`analyzers/semgrep`, `analyzers/spotbugs`** - `parse` CLIs for analyzer output
- **`cmd/dedupe`, `cmd/siteindex`** - standalone utility CLIs
